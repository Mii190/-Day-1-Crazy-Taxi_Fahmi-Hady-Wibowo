## DOKUMENTASI MATERI WORKSHOP

Prompt Engineering merupakan cara merancang instruksi agar AI dapat memberikan jawaban atau hasil yang tepat, relevan, dan sesuai dengan kebutuhan pengguna.

Prompt sendiri merupakan instruksi atau masukan yang diberikan kepada model AI untuk mendapatkan hasil tertentu. Bentuknya dapat berupa pertanyaan sederhana, kata kunci, instruksi kompleks, hingga potongan kode.

## Pentingnya Context dalam Prompt

Context atau konteks merupakan informasi tambahan yang diberikan kepada AI agar AI dapat memahami tujuan dan kebutuhan pengguna dengan lebih baik.

Pemberian konteks yang jelas dapat membantu AI menghasilkan jawaban yang lebih spesifik dibandingkan hanya memberikan instruksi singkat tanpa penjelasan.

Role: Menentukan peran yang harus dijalankan oleh AI.

Task: Menjelaskan tugas yang harus dikerjakan oleh AI.

Context: Memberikan latar belakang dan informasi pendukung.

Format: Menentukan bentuk atau struktur hasil yang diharapkan.

## GIT & GITHUB

1. Git merupakan Version Control System (VCS) yang digunakan untuk melacak perubahan pada file dalam suatu proyek.

Git memungkinkan pengguna mengetahui siapa yang melakukan perubahan, kapan perubahan dilakukan, dan apa saja perubahan yang terjadi.

Git diciptakan oleh Linus Torvalds pada tahun 2005.


2. GitHub merupakan platform berbasis web yang digunakan untuk menyimpan repository Git secara online/Cloud.

GitHub juga menyediakan fasilitas untuk berkolaborasi, berbagi kode, serta mengelola pengembangan proyek bersama pengguna lain.

## GIT WORKFLOW

- Working Directory

Working Directory merupakan salinan proyek yang sedang dikerjakan pada komputer. Di bagian ini, pengguna dapat membuat, mengubah, dan menghapus file.

- Staging Area

Staging Area merupakan tempat untuk menyimpan informasi perubahan yang akan dimasukkan ke dalam commit berikutnya.

Pengguna dapat menentukan perubahan mana saja yang akan disimpan.

- Git Directory (Repository)

Git Directory merupakan tempat Git menyimpan metadata dan object database dari sebuah proyek. Bagian ini menyimpan informasi yang dibutuhkan Git untuk mengelola perubahan proyek.

## PERINTAH DASAR GIT

git init: Membuat repository Git baru pada direktori proyek.

git add .: Menambahkan perubahan file ke Staging Area.

git add --all: Menambahkan seluruh perubahan ke Staging Area.

git add -A: Memiliki fungsi yang sama dengan git add --all.

git add *: Menambahkan file yang sesuai dengan pola wildcard ke Staging Area.

git commit -m "message": Menyimpan perubahan ke dalam repository dengan pesan commit.

git remote add origin <url>: Menghubungkan repository lokal dengan repository remote.

git push origin main: Mengirim commit pada branch main ke repository remote.

git pull origin main: Mengambil perubahan dari branch main pada repository remote dan menggabungkannya ke branch aktif.

git clone <url>: Menyalin repository remote ke komputer lokal.
